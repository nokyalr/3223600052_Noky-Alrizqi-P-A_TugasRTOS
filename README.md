## 🧾 Deskripsi Umum

Repositori ini berisi **kumpulan tugas (Task 1–Task 2)** untuk mata kuliah **RTOS (Real-Time Operating System)** menggunakan **ESP32-S3 DevKitC-1** dan **Wokwi Simulator**.
Setiap task difokuskan pada penerapan konsep **FreeRTOS multitasking**, **dual-core processing**, dan **sinkronisasi antar-task** dengan berbagai peripheral I/O.

---

## ⚙️ Perangkat & Software yang Digunakan

### 🧠 Hardware

* ESP32-S3 DevKitC-1
* LED, Push Button, Buzzer
* Potentiometer
* OLED Display (SSD1306, I²C 128×64)
* Servo Motor
* Stepper Motor (A4988 Driver)
* Rotary Encoder

### 💻 Software

* **VSCode + PlatformIO**
* **Wokwi Simulator**
